# FreshCart Vegetable Store

Full-stack starter implementation based on the supplied requirements.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: SQLite
- Authentication: JWT + bcrypt
- Responsive customer storefront and admin dashboard
- Dynamic package customization driven by package totals/default counts

## Run
### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

Default admin:
- Email: admin@freshcart.local
- Password: Admin@123

The database is created automatically on first backend start.
